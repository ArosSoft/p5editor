# Урок 1: Настройка игрового поля

Добро пожаловать в мир создания игр! Сегодня мы сделаем игру "Аэрохоккей" - динамичную игру для двоих игроков. Начнём с создания игрового поля.

## Что такое логические координаты?
Мы будем использовать логический размер поля 800x450 пикселей. Это позволит правильно масштабировать игру на любом экране.

## Наша первая программа
В окне редактора ты видишь начальный шаблон кода. Вот две самые главные функции:

1. **`function setup()`** — выполняется один раз в самом начале. Здесь мы создаём холст и задаём границы поля.
2. **`function draw()`** — выполняется снова и снова. Здесь мы рисуем всё игровое поле.

## Пишем код
Замени шаблон на этот код в редакторе:

```javascript
let LOGIC_W = 800;  // Ширина логического поля
let LOGIC_H = 450;  // Высота логического поля
let padding = 25;   // Отступ от краёв

// Границы поля
let fieldLeft, fieldRight, fieldTop, fieldBottom;

function setup() {
  createCanvas(LOGIC_W, LOGIC_H);  // Создаём холст
  calculateField();  // Вычисляем границы
}

function draw() {
  background(20, 20, 40);  // Тёмный фон (цвет ночного неба)
  
  // Рисуем игровое поле (светло-синий прямоугольник)
  noStroke();
  fill(15, 25, 50);
  rect(fieldLeft, fieldTop, fieldRight - fieldLeft, fieldBottom - fieldTop, 8);
}

function calculateField() {
  // Вычисляем границы игрового поля
  fieldLeft = padding;
  fieldRight = LOGIC_W - padding;
  fieldTop = padding;
  fieldBottom = LOGIC_H - padding;
}
```
