# Урок 5: Столкновение шайбы с игроками

Отлично! Шайба летает и отскакивает от стен! Теперь научим её отскакивать от игроков.

## Как проверить столкновение?
Мы будем измерять расстояние между центрами шайбы и игрока. Если оно меньше суммы радиусов - они столкнулись.

## Добавляем столкновение

```javascript
function updatePuck() {
  // ... предыдущий код ...
  
  // Проверяем столкновение с игроками
  checkPlayerCollision(leftPlayer);
  checkPlayerCollision(rightPlayer);
}

function checkPlayerCollision(player) {
  // Вычисляем расстояние между шайбой и игроком
  let dx = puck.x - player.x;
  let dy = puck.y - player.y;
  let dist = sqrt(dx*dx + dy*dy);
  
  // Минимальное расстояние для столкновения
  let minDist = playerRadius + puckRadius;
  
  // Если расстояние меньше - произошло столкновение
  if (dist < minDist && dist > 0) {
    // Разделяем объекты (убираем наложение)
    let overlap = minDist - dist;
    let nx = dx / dist;  // Нормализованный вектор по X
    let ny = dy / dist;  // Нормализованный вектор по Y
    
    puck.x += nx * overlap;
    puck.y += ny * overlap;
    
    // Вычисляем отскок (отражение скорости)
    let dot = puck.vx * nx + puck.vy * ny;
    if (dot < 0) {
      puck.vx -= 2 * dot * nx;
      puck.vy -= 2 * dot * ny;
    }
  }
}
```
